# Blackjack-Simulation-Win-Probability
Ran 120,000 simulation of blackjack games in RStudio analyzing the different win probabilities with different hit limits for the players.
Found win probability given the dealer's first card (2-11).
Used conditional formatting to create an easy visualization to read the different win probabilities.
Found the player hit limit is 14 given the dealer's first card is 6 has the highest win probability of 56%
